# 양도소득세 (2024-2025년 기준)

## 1. 기본 세율 (일반 부동산)

### 보유기간별 세율
| 보유기간 | 일반 부동산 | 주택 (조정대상지역) |
|---------|-----------|-----------------|
| 1년 미만 | 50% | 70% |
| 1년~2년 미만 | 40% | 60% |
| 2년 이상 | 기본세율(6~45%) | 기본세율(6~45%) |

### 기본세율 (종합소득세율)
| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1,400만원 이하 | 6% | - |
| 1,400만~5,000만원 | 15% | 126만원 |
| 5,000만~8,800만원 | 24% | 576만원 |
| 8,800만~1.5억 | 35% | 1,544만원 |
| 1.5억~3억 | 38% | 1,994만원 |
| 3억~5억 | 40% | 2,594만원 |
| 5억~10억 | 42% | 3,594만원 |
| 10억 초과 | 45% | 6,594만원 |

## 2. 다주택자 중과

### 중과세율 (조정대상지역)
| 구분 | 추가 세율 |
|------|---------|
| 2주택 | 기본세율 + 20%p |
| 3주택 이상 | 기본세율 + 30%p |

- 비조정지역: 중과 미적용 (기본세율)
- 2024년 5월까지 한시적 중과 유예 (연장 여부 확인 필요)

## 3. 장기보유특별공제

### 일반 부동산
| 보유기간 | 공제율 |
|---------|-------|
| 3년 이상 | 연 2% |
| 최대 15년 | 30% |

### 1세대 1주택 (거주 요건 충족)
| 보유기간 | 공제율 (보유) | 공제율 (거주) |
|---------|-------------|-------------|
| 3년 이상 | 연 4% | 연 4% |
| 최대 | 40% (10년) | 40% (10년) |
| 합계 최대 | 80% |

- 보유 10년 이상 + 거주 10년 이상 → 양도차익의 80% 공제

### 다주택자
- 조정대상지역 중과 시: 장기보유특별공제 적용 불가
- 비조정지역: 일반 공제율 적용

## 4. 1세대 1주택 비과세

### 비과세 요건
1. 보유기간 2년 이상
2. 조정대상지역: 보유 2년 + 거주 2년
3. 양도가액 12억원 이하 (12억 초과 시 초과분만 과세)

### 비과세 불가 케이스
- 보유기간 2년 미만
- 다주택 상태에서 양도
- 일시적 2주택 특례 기간 초과

### 일시적 2주택 특례
- 종전주택 취득일로부터 1년 이후 신규주택 취득
- 신규주택 취득 후 3년 이내 종전주택 양도 시 비과세

## 5. 양도소득세 계산 절차

```
양도가액 (매도가)
- 취득가액 (매입가 + 취득세 등)
- 필요경비 (중개수수료, 수리비 등)
= 양도차익

양도차익
- 장기보유특별공제
= 양도소득금액

양도소득금액
- 기본공제 (연 250만원)
= 과세표준

과세표준 × 세율 = 산출세액
산출세액 - 감면세액 = 납부세액
```

## 6. 경매 취득 시 취득가액 산정

### 취득가액에 포함되는 비용
1. 낙찰대금 (매각대금)
2. 취득세, 등록면허세
3. 법무사 수수료
4. 인지세, 증지대
5. 명도비용 (합의금, 이사비 등)
6. 인테리어 비용 (자본적 지출에 해당하는 경우)

### 취득가액에 불포함
- 대출이자
- 관리비 연체분 대납액 (일부 논란)

## 7. 양도소득세 계산 예시

### 예시: 경매로 5억 낙찰, 3년 보유 후 7억에 매도 (1주택)
1. 양도가액: 7억원
2. 취득가액: 5억 + 취득세 565만원 + 기타 200만원 = 5억 765만원
3. 양도차익: 7억 - 5억 765만원 = 1억 9,235만원
4. 장기보유공제 (3년, 1주택 거주): 1억 9,235만 × 24% = 4,616만원
5. 양도소득금액: 1억 4,619만원
6. 기본공제: 250만원
7. 과세표준: 1억 4,369만원
8. 세율 (35%): 1억 4,369만 × 35% - 1,544만 = 3,485만원
9. 지방소득세 (10%): 348만원
10. **납부세액: 약 3,833만원**

### 예시: 12억 초과 1주택 비과세 부분과세
양도가 15억, 취득가 10억 (12억 초과분만 과세):
1. 양도차익: 5억원
2. 과세대상: 5억 × (15억 - 12억) / 15억 = 1억원
3. 나머지 4억원은 비과세

## 8. 신고 및 납부

- **신고기한**: 양도일이 속하는 달의 말일로부터 2개월 이내
- **예정신고**: 양도 시마다 신고
- **확정신고**: 다음 해 5월 (2건 이상 양도 시)
- 미신고 가산세: 납부세액의 20%
- 과소신고 가산세: 추가납부세액의 10%
