# 부동산 취득세 (2024-2025년 기준)

## 1. 주택 취득세율

### 1주택자 (조정대상지역 외)
| 취득가액 | 세율 |
|---------|------|
| 6억원 이하 | 1% |
| 6억원 초과 ~ 9억원 이하 | 1% ~ 3% (점진적) |
| 9억원 초과 | 3% |

- 6~9억 구간 세율 계산: (취득가액 × 2/3억 - 3) %
- 예시: 7.5억 → (7.5 × 2/3 - 3) = 2% → 취득세 1,500만원

### 1주택자 (조정대상지역)
- 동일하게 1~3% 적용 (2023년 이후 완화)

### 다주택자 중과세율
| 구분 | 조정대상지역 | 비조정지역 |
|------|------------|-----------|
| 2주택 | 8% | 1~3% (일반세율) |
| 3주택 이상 | 12% | 8% |
| 법인 | 12% | 12% |

### 비주거용 부동산
| 용도 | 세율 |
|------|------|
| 오피스텔 (주거용) | 주택 세율 적용 |
| 오피스텔 (업무용) | 4% |
| 상가/사무실 | 4% |
| 토지 | 4% |

## 2. 부가세 (취득세에 추가로 납부)

### 지방교육세
- 취득세의 10%
- 예: 취득세 300만원 → 지방교육세 30만원

### 농어촌특별세
- 전용면적 85㎡ 초과 주택: 취득세의 20%
- 전용면적 85㎡ 이하 주택: 비과세
- 예: 취득세 300만원 (85㎡ 초과) → 농특세 60만원

## 3. 인지세 (등기 시 납부)

| 매매가액 (취득가액) | 인지세 |
|-------------------|--------|
| 1억원 이하 | 비과세 |
| 1억원 초과 ~ 10억원 이하 | 15만원 |
| 10억원 초과 | 35만원 |

## 4. 경매 특수사항

### 과세표준
- **경매 낙찰가(매각대금)가 과세표준**
- 감정가가 아닌 실제 낙찰가 기준으로 취득세 계산
- 매각허가결정일이 취득일

### 납부 기한
- 잔금 납부일(소유권이전등기일)로부터 60일 이내
- 기한 내 미납 시 가산세 20% 부과

### 취득세 계산 예시 (경매)
낙찰가 5억원, 1주택, 전용면적 84㎡ 아파트:
1. 취득세: 5억 × 1% = 500만원
2. 지방교육세: 500만 × 10% = 50만원
3. 농어촌특별세: 85㎡ 이하이므로 비과세
4. 인지세: 15만원
5. **합계: 565만원**

낙찰가 12억원, 1주택, 전용면적 120㎡ 아파트:
1. 취득세: 12억 × 3% = 3,600만원
2. 지방교육세: 3,600만 × 10% = 360만원
3. 농어촌특별세: 3,600만 × 20% = 720만원 (85㎡ 초과)
4. 인지세: 35만원
5. **합계: 4,715만원**

## 5. 종합부동산세 (보유세, 매년 납부)

### 과세 기준
- 1주택자: 공시가격 12억원 초과분
- 다주택자: 공시가격 합산 9억원 초과분

### 세율
| 과세표준 | 1주택 | 다주택 |
|---------|-------|--------|
| 3억 이하 | 0.5% | 0.5% |
| 3~6억 | 0.7% | 0.7% |
| 6~12억 | 1.0% | 1.0% |
| 12~25억 | 1.3% | 1.3% |
| 25~50억 | 1.5% | 2.0% |
| 50~94억 | 2.0% | 3.0% |
| 94억 초과 | 2.7% | 5.0% |

## 6. 재산세 (보유세, 매년 납부)

### 주택
| 과세표준 | 세율 |
|---------|------|
| 6천만원 이하 | 0.1% |
| 6천만원~1.5억 | 0.15% |
| 1.5억~3억 | 0.25% |
| 3억 초과 | 0.4% |

- 과세표준 = 공시가격 × 60% (공정시장가액비율)
- 7월, 9월 두 번 나누어 납부

### 비주거용
- 건물: 0.25%
- 토지: 0.2~0.5%
