# 주택임대차보호법 (2024-2025년 기준)

## 1. 적용 대상

### 보호 대상
- **주거용 건물**의 임대차 (주택, 아파트, 빌라, 다세대, 오피스텔 주거용)
- 미등기 주택도 적용
- 임차인이 **자연인** (법인은 원칙적 미적용, 소규모 법인 예외)
- 임대차 계약서 없이 구두 계약도 보호 (다만 입증 곤란)

### 비적용 대상
- 상가 임대차 → 상가건물임대차보호법 별도 적용
- 임차보증금 없는 무상 사용 (사용대차)
- 법인 명의 임차 (원칙)

### 오피스텔 적용 기준
- **주거용으로 실제 사용** 시 주택임대차보호법 적용
- 건축물대장 용도와 무관, **실제 용도** 기준
- 사업자등록을 한 업무용 오피스텔은 상가법 적용

## 2. 대항력

### 대항력이란?
임차인이 제3자(경매 낙찰자 포함)에게 임대차 관계를 주장할 수 있는 권리.
대항력이 있으면 보증금을 돌려받기 전까지 퇴거를 거부할 수 있음.

### 대항력 취득 요건 (2가지 모두 충족)
1. **주택의 인도** (점유, 실제 거주)
2. **전입신고** (주민등록 이전)

### 대항력 발생 시점
- 전입신고 + 점유 완료한 **다음 날 00:00** (익일 0시)
- ⚠️ **당일 효력 없음** → 같은 날 설정된 근저당보다 후순위

### 대항력 판단 예시
```
2024.03.01 - (근)저당권 설정 (은행)
2024.03.01 - 임차인 전입신고 + 점유 개시
→ 대항력 발생: 2024.03.02 00:00
→ 결과: 임차인이 후순위 (대항력 없음, 저당보다 늦음)

2024.02.28 - 임차인 전입신고 + 점유 개시
2024.03.01 - (근)저당권 설정
→ 대항력 발생: 2024.03.01 00:00
→ 결과: 임차인이 선순위 (대항력 있음)
```

### 대항력 유지 요건
- 전입신고 + 점유를 **계속 유지**해야 함
- 전입을 다른 곳으로 옮기면 대항력 상실
- 가족 중 1인이라도 전입 유지 시 대항력 유지 (판례)

### 대항력과 경매
| 임차인 상태 | 경매 낙찰자에게 미치는 영향 |
|------------|------------------------|
| 선순위 대항력 + 배당미요구 | **보증금 전액 인수** (낙찰자 부담) |
| 선순위 대항력 + 배당요구 | 배당으로 수령, 부족분은 인수 가능 |
| 후순위 대항력 | 소멸 (보증금 보호 못 받음) |
| 대항력 없음 | 소멸 (인도명령 대상) |

## 3. 확정일자와 우선변제권

### 확정일자란?
- 임대차 계약서에 관공서가 날짜를 확인해 찍어주는 도장
- 취득 장소: 주민센터, 등기소, 법원, 공증사무소
- 비용: 600원
- 전자계약 시 자동 부여

### 우선변제권 취득 요건 (3가지 모두 충족)
1. **대항요건** (전입신고 + 점유)
2. **확정일자**
3. 배당요구 종기까지 **배당요구** 신청

### 우선변제권 효력
- 확정일자 기준으로 다른 담보권자와 **순위 경쟁**
- 배당 시 확정일자 순서대로 배당받음
- 근저당과 같은 날 설정 시: 근저당이 우선 (대항력 익일 발생 원칙)

### 확정일자 vs 대항력 vs 우선변제권 비교
| 항목 | 대항력 | 우선변제권 |
|------|-------|----------|
| 요건 | 전입+점유 | 전입+점유+확정일자 |
| 효력 | 거주 유지 (퇴거 거부) | 배당에서 보증금 회수 |
| 없으면 | 경매 시 쫓겨남 | 배당 못 받음 |

## 4. 소액임차인 최우선변제

### 제도 취지
보증금이 소액인 서민 임차인을 특별 보호하기 위해,
담보물권(근저당)보다 **우선하여 배당**받을 수 있는 권리.

### 최우선변제 요건
1. **대항요건 구비** (전입+점유)
2. **배당요구 종기까지 배당요구** 신청
3. 보증금이 지역별 한도 이하
4. 확정일자 불요 (없어도 됨)

### 소액임차인 기준 및 최우선변제금 (2024년 기준)
| 지역 | 보증금 한도 | 최우선변제금 |
|------|-----------|------------|
| 서울특별시 | 1억 6,500만원 이하 | 5,500만원 |
| 수도권 과밀억제권역 (인천, 의정부, 구리, 남양주, 하남, 고양, 수원, 성남, 안양, 부천, 광명, 과천, 의왕, 군포, 시흥) | 1억 4,500만원 이하 | 4,800만원 |
| 광역시 (서울 제외), 세종시, 안산, 용인, 김포, 광주시, 파주 | 8,500만원 이하 | 2,800만원 |
| 기타 지역 | 7,500만원 이하 | 2,500만원 |

### 최우선변제 한도
- 주택가액(매각가)의 **1/2** 범위 내에서만 최우선변제
- 여러 소액임차인이 있으면 비율대로 안분 배당
- 예) 매각가 2억, 소액임차인 3명: 최대 1억까지만 안분

### ⚠️ 경매 시 주의
- 소액임차인이 여러 명이면 **배당금 부족** 가능
- 낙찰자는 소액임차인 최우선변제금만큼 실질 낙찰가가 높아지는 효과
- 소액임차인 수와 보증금을 반드시 현황조사서에서 확인

## 5. 배당 순위 (상세)

### 경매 배당 순서
```
1순위: 경매 비용 (집행비용)
2순위: 최우선변제 소액임차인
3순위: 당해세 (해당 부동산에 부과된 재산세, 종합부동산세)
4순위: 확정일자 임차인 / (근)저당권 (설정일 순서대로)
5순위: 일반 조세 (국세, 지방세 - 법정기일 기준)
6순위: 임금채권 (근로기준법)
7순위: 일반 채권자
8순위: 후순위 권리자
9순위: 채무자 (소유자, 잔여금 반환)
```

### 당해세란?
- **해당 부동산 자체에 부과된 세금**
- 재산세, 종합부동산세, 도시계획세 등
- 일반 국세/지방세보다 우선 (3순위)
- 근저당보다도 우선할 수 있어 배당에 큰 영향

### 배당 판단 예시
```
매각가: 5억원
경매비용: 500만원

1) 소액임차인 A (보증금 8,000만): 최우선변제 5,500만원
2) 당해세 (재산세 체납): 200만원
3) 1순위 근저당 (은행): 3억원
4) 확정일자 임차인 B: 1억원

배당:
경매비용: 500만원 → 잔여: 4억9,500만원
소액임차인 A: 5,500만원 → 잔여: 4억4,000만원
당해세: 200만원 → 잔여: 4억3,800만원
1순위 근저당: 3억원 → 잔여: 1억3,800만원
임차인 B: 1억원 → 잔여: 3,800만원
→ 채무자 반환: 3,800만원
```

## 6. 경매 권리분석 체크리스트

### 필수 확인 서류
1. **등기부등본** (등기사항전부증명서)
   - 갑구: 소유권 관련 (가압류, 가처분, 가등기, 경매개시결정)
   - 을구: 담보권 관련 (근저당, 전세권, 저당권)
2. **현황조사서**: 임차인 현황, 점유자, 보증금, 전입일
3. **매각물건명세서**: 인수되는 권리, 특이사항
4. **감정평가서**: 가격 산정 근거, 건물 상태

### 말소기준권리 판단
```
등기부 을구에서 가장 빠른 담보권(근저당/압류) 찾기
  ↓
그 날짜가 "말소기준권리 설정일"
  ↓
이 날짜 이후 설정된 권리 → 매각 시 소멸
이 날짜 이전 설정된 권리 → 인수 (낙찰자 부담)
```

### 인수되는 권리 (위험 요소)
| 권리 | 설명 | 위험도 |
|------|------|--------|
| 선순위 전세권 | 보증금 전액 인수 | ⚠️ 높음 |
| 선순위 대항력 임차인 (배당미요구) | 보증금 인수 | ⚠️ 높음 |
| 유치권 | 공사대금 등 인수 가능 | ⚠️⚠️ 매우 높음 |
| 법정지상권 | 토지 사용권 인수 | ⚠️ 높음 |
| 분묘기지권 | 묘지 철거 곤란 | ⚠️ 높음 |
| 지역권 | 통행권 등 인수 | 보통 |

### 안전한 물건 판단 기준
1. ✅ 선순위 임차인 없음 (또는 모두 배당요구 완료)
2. ✅ 유치권 신고 없음
3. ✅ 법정지상권 해당 없음 (토지+건물 동일 소유)
4. ✅ 전입세대 확인 완료
5. ✅ 체납 관리비 확인

## 7. 임차인 유형별 경매 대응

### 임차인 분석 플로우차트
```
임차인 존재?
  ├─ NO → 안전 (점유자 확인만)
  └─ YES ↓
      대항력 있음? (전입+점유가 말소기준권리보다 선순위?)
        ├─ NO → 소멸 (인도명령 가능)
        └─ YES ↓
            배당요구 했음?
              ├─ YES → 배당으로 수령 → 부족분만 인수 가능
              └─ NO → ⚠️ 보증금 전액 인수 (낙찰자 부담)
```

### 실무 팁
- 현황조사서의 임차인 진술이 항상 정확하지 않음 → 직접 방문 확인 권장
- 전입세대 열람으로 실제 전입자 확인 (주민센터)
- 배당요구 종기 전에 배당요구 여부 확인 불가 → 최악의 시나리오로 분석
- 보증금이 높은 선순위 임차인이 배당미요구 시 낙찰가에 보증금 추가 부담
