# 부동산 경매 절차 및 법률 (2024-2025년 기준)

## 1. 경매 절차 개요

```
경매개시결정 → 감정평가 → 매각기일공고 → 입찰 → 낙찰(매각허가)
→ 대금납부 → 소유권이전등기 → 명도(인도)
```

## 2. 입찰 절차

### 입찰 준비
1. 물건 조사: 등기부등본, 현황조사서, 감정평가서 확인
2. 권리분석: 말소기준권리 확인, 인수되는 권리 파악
3. 현장 답사: 점유자 확인, 건물 상태 확인
4. 입찰가 결정: 감정가 대비 낙찰가율 참고

### 입찰 방법
- 기일입찰: 법원 경매법정에서 입찰표 제출
- 기간입찰: 1주일간 입찰 (대부분 법원에서 시행)
- 입찰보증금: 최저매각가격의 10% (보증금 봉투에 넣어 제출)
- 입찰표에 입찰가격 기재 → 최고가 입찰자에게 매각

### 유찰 시
- 다음 매각기일에 최저가 20~30% 인하 (법원마다 다름)
- 통상 20% 씩 인하
- 3회 이상 유찰 시 특별매각 가능

## 3. 낙찰 후 절차

### 매각허가결정
- 낙찰일로부터 1주일 뒤 매각허가결정
- 이해관계인의 항고가 없으면 1주일 후 확정
- 매각허가결정 확정 후 1개월 이내 잔금 납부

### 대금 납부
- 잔금 = 낙찰가 - 입찰보증금(10%)
- 대출 가능 (경매 잔금 대출)
- 납부기한 내 미납 시: 재매각 + 보증금 몰수

### 소유권이전등기
- 잔금 납부 → 법원이 등기촉탁
- 등기 시 필요: 취득세 납부 영수증, 등록면허세, 인지세
- 등기완료 후 등기필증 수령

## 4. 명도 (인도)

### 임의 명도
1. 점유자에게 연락하여 퇴거 협의
2. 이사비 협의 (통상 200~500만원)
3. 합의 후 퇴거 확인, 열쇠 인수

### 강제 명도 (인도명령)
1. 대금 납부 후 6개월 이내 인도명령 신청
2. 법원이 인도명령 결정 (통상 1~2주)
3. 결정문 송달 후 강제집행 신청
4. 집행관이 강제퇴거 실행 (집행비용 100~300만원)

### 인도명령 대상
- 채무자 (소유자)
- 대항력 없는 임차인
- 불법 점유자

### 인도명령 불가 대상
- 대항력 있는 임차인 (보증금 전액 수령 전)
- 유치권자 (인정되는 경우)

## 5. 권리분석

### 말소기준권리
경매로 매각 시 **말소기준권리보다 후순위 권리**는 소멸됨.

말소기준권리가 되는 것:
1. (근)저당권
2. 압류 (가압류 포함)
3. 담보가등기
4. 경매개시결정 기입등기

### 인수되는 권리 (소멸되지 않음)
1. 말소기준권리보다 **선순위** 권리:
   - 선순위 전세권
   - 선순위 지상권
   - 선순위 지역권
2. 법정지상권
3. 분묘기지권
4. 유치권 (별도 판단 필요)

### 임차인 분석
| 구분 | 대항력 | 배당 | 인수 여부 |
|------|-------|------|---------|
| 선순위 대항력 + 배당요구 | O | O | 배당으로 소멸 |
| 선순위 대항력 + 배당미요구 | O | X | **인수** (보증금 부담) |
| 후순위 대항력 | X | △ | 소멸 |
| 대항력 없음 | X | X | 소멸 |

대항력 요건:
- 주택: 전입신고 + 점유 (다음날 0시 효력 발생)
- 상가: 사업자등록 + 점유

확정일자:
- 우선변제권 취득 (배당받을 수 있는 권리)
- 주민센터 또는 등기소에서 확정일자 부여

## 6. 배당

### 배당 순위
1. 경매비용
2. 최우선변제 소액임차인 (지역별 한도)
3. 조세 (당해세: 재산세, 종부세)
4. 1순위 (근)저당권 / 확정일자 임차인 (설정일 순)
5. 2순위 이하 권리자
6. 일반채권자
7. 채무자 (소유자)

### 소액임차인 최우선변제 (2024년 기준)
| 지역 | 보증금 한도 | 최우선변제금 |
|------|-----------|------------|
| 서울 | 1.65억 이하 | 5,500만원 |
| 수도권 과밀억제권역 | 1.45억 이하 | 4,800만원 |
| 광역시 등 | 8,500만원 이하 | 2,800만원 |
| 기타 지역 | 7,500만원 이하 | 2,500만원 |

## 7. 주의사항 (리스크)

### 반드시 확인할 사항
1. **등기부등본**: 소유자, 채권자, 설정일자 확인
2. **현황조사서**: 점유자, 임차인 현황
3. **매각물건명세서**: 인수되는 권리 기재
4. **감정평가서**: 건물 상태, 토지 형상

### 주요 리스크
1. **유치권**: 공사대금 유치권 주장 시 인수 가능성
2. **선순위 임차인**: 보증금 인수 부담
3. **법정지상권**: 토지만 낙찰 시 건물 소유자의 권리
4. **농지취득자격증명**: 농지 낙찰 시 필수 (미취득 시 매각불허가)
5. **토지별도등기**: 집합건물에서 토지만 별도 경매 시 복잡

### 경매 비용 총정리
| 항목 | 금액 |
|------|------|
| 낙찰대금 | 입찰가 |
| 취득세+부가세 | 낙찰가의 1~12% |
| 인지세 | 0~35만원 |
| 등록면허세 | 건당 약 6,000원 |
| 법무사 수수료 | 30~100만원 |
| 명도비 | 0~500만원 (협의) |
| 인테리어 | 물건에 따라 다름 |
